# Рулетка напитков

Веб-приложение "Рулетка напитков" — крути барабан и узнай, что выпьем сегодня.

## Что умеет

- Слот-машина с тремя барабанами и анимацией
- Два режима: "Сразу всё" (напиток) и "Категория → напиток"
- Фильтры: только лёгкое (до 6%), макс. крепость, исключение категорий
- Темы: подборки напитков под событие
- Свой бар: добавляйте собственные напитки
- Коллекция: открытые напитки, ачивки, прогресс по категориям
- Профиль: уровни, статистика, история спинов
- Поиск по всем напиткам
- Звук, вибрация, конфетти, шаринг результата

## Запуск локально

Просто откройте index.html в браузере. Приложение полностью статическое — сервер не нужен.

## Деплой

Сайт публикуется на GitHub Pages:
https://alexey0bashkin.github.io/drinks/

Настройка: Settings → Pages → Source: Deploy from a branch → Branch: main, папка / (root).

## Структура

- index.html — разметка всех экранов
- style.css — стили, тёмная тема, анимации
- app.js — логика: слот-машина, фильтры, коллекция, профиль
- drinks.js — данные: категории, напитки, темы

## Технологии

Чистый HTML + CSS + JavaScript без фреймворков и сборки. Данные хранятся в localStorage.
